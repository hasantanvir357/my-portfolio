About Me

My Journey into Full-Stack Development

My programming journey began with curiosity — exploring how everyday websites work, then steadily moving from simple HTML and CSS pages to building complete, production-grade applications. That transition into full-stack development became the turning point of my career: I discovered that clean code and thoughtful design can genuinely improve people’s daily lives.

Today I work across the entire MERN stack. On the frontend I build interactive, responsive interfaces with React & Next.js — component-driven architecture, careful state management and pixel-polished styling with Tailwind CSS. On the backend I design REST APIs with Node.js & Express, model data in MongoDB, and wire up secure authentication flows that scale.
