About Me

A quick look at my journey, what drives me, and how I keep growing as a developer.

My Journey into Frontend

I started my programming journey with curiosity — first exploring the logic behind everyday websites, then steadily moving from basic HTML and CSS pages to building real, production-grade applications. That transition into frontend development became the turning point of my career: I discovered that clean code and thoughtful design can genuinely improve people’s daily lives.

Today I focus on building scalable web applications with React & Next.js — using the App Router, server components, and TypeScript to keep codebases maintainable and fast. Along the way I have deepened my understanding of UI/UX principles, accessible component design, responsive layout systems, and state management patterns that scale from simple hooks to complex application stores.

To become a well-rounded developer, I also picked up the backend basics with Node.js & Express — designing REST APIs, working with MongoDB Atlas, and handling authentication flows. Understanding the full picture makes my frontend work sharper, more realistic, and easier to integrate.
